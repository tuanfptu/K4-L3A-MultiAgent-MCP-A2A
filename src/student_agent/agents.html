02 / AGENT RESPONSIBILITIES

Nhiệm vụ của từng agent.

Mỗi thẻ trả lời ba câu hỏi: agent nhận gì, xử lý gì và bàn giao gì. Tool tùy điều kiện được ghi rõ bên dưới.

01 Coordinator02 Order03 Payment04 Shipment05 Policy06 Verifier
AGENT 01 / 06Orchestration

Coordinator

Điểm vào của case và nơi gom kết quả từ các specialist.

Nhận vào
case_id, order ID khách khai, claim, policy_version và thời điểm opened_at.
Xử lý
Khám phá tool khả dụng; giao bốn lượt đọc cốt lõi, thêm refund hoặc seller khi chủ đề cần; ghi nhận tool lỗi và handoff.
Bàn giao
Evidence theo đúng case để phân loại issue, rồi hoàn tất output và trace.
list_tools (discovery)task_assignedhandoff

Coordinator chỉ khám phá tool; MCP evidence được lấy bởi các vai trò chuyên trách.

AGENT 02 / 06Evidence specialist

Order agent

Xác minh đơn, item và seller thuộc đúng order đang điều tra.

Nhận vào
case_id và claimed_order_id từ Coordinator.
Xử lý
Đọc trạng thái đơn, item, giá, phí vận chuyển, shipping limit và seller ID; chỉ giữ item đúng order và khung thời gian phù hợp.
Bàn giao
Facts về đơn và entity IDs, kèm evidence_ref cho từng tool đã dùng.
get_orderget_order_itemsget_sellers*

* get_sellers chỉ gọi khi claim liên quan unavailable_order_paid hoặc late_delivery_seller.

AGENT 03 / 06Evidence specialist

Payment agent

Đối soát dòng tiền và diễn tiến hoàn tiền.

Nhận vào
case_id, order ID và câu hỏi về thanh toán hoặc refund.
Xử lý
Đọc capture, mismatch và refund events trong khoảng từ lúc mua đến opened_at; phân biệt duplicate charge với split payment hợp lệ.
Bàn giao
Số tiền capture, trạng thái refund và evidence_ref hỗ trợ kết luận.
get_payment_timelineget_refund_timeline*

* get_refund_timeline chỉ gọi khi claim là refund_pending hoặc refund_failed.

AGENT 04 / 06Evidence specialist

Shipment agent

Xác định hàng có đến trễ và dấu hiệu trách nhiệm nằm ở đâu.

Nhận vào
case_id, order ID và mốc shipping limit từ item.
Xử lý
So sánh carrier handoff, estimated delivery và actual delivery; đối chiếu sự kiện delivered_late và actor nếu có.
Bàn giao
Tình trạng giao hàng, dấu hiệu seller hay logistics gây trễ, cùng evidence_ref.
get_shipment_summary

Timeline events sau opened_at bị loại; estimated delivery được so với thời điểm mở case.

AGENT 05 / 06Decision specialist

Policy agent

Biến issue đã được xác minh thành hành động xử lý theo phiên bản policy.

Nhận vào
policy_version của case và issue do classifier suy ra từ evidence.
Xử lý
Tải policy, chọn rule của issue; xác định case_status, recommended_action, refund_brl và responsible_parties.
Bàn giao
Quyết định, số tiền đề xuất và policy evidence_ref. Không có rule thì chuyển needs_investigation, refund 0.
get_policypolicy_decided

Policy được tải trong pha thu thập; rule chỉ áp dụng sau khi phân loại issue.

AGENT 06 / 06Verification

Verifier + contract gate

Phát hiện thiếu evidence và chặn output sai cấu trúc hoặc provenance.

Nhận vào
Tool failures, output dự kiến và các evidence_ref của case.
Xử lý
Workflow ghi PASS hoặc PARTIAL_EVIDENCE vào trace. Sau đó CLI kiểm tra JSON Schema; lệnh validate kiểm tra ref linkage, claim refs và tổng refund.
Bàn giao
Output JSON hợp lệ cùng trace có thể đối chiếu; lỗi validation được báo để sửa.
verification_completedday09 validate

Không gọi MCP tool. Kiểm tra schema và tiền được thực hiện ở các bước validate sau workflow.
